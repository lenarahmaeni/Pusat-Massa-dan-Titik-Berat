Pusat Massa & Titik Berat

Titik kuning = Pusat Massa / Titik Berat. Segitiga abu-abu = Titik Tumpu. Jika Pusat Massa berada tepat di atas Titik Tumpu, sistem dalam kondisi SEIMBANG.

Modul Formulasi & Analisis Perhitungan

Rumus Pusat Massa: Xcm = (m1 · x1 + m2 · x2) / (m1 + m2)
Syarat Seimbang: Xcm = 0 cm  |  x2 seimbang = -(m1 · x1) / m2
